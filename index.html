A university team project extending an existing VR driving application. My work centres on making physical and VR controls behave predictably across real hardware.

03Personal tool個人ツール

Python / Anki / KanjiVG / KANJIDIC2

auto_kanji_info

An Anki add-on created for my own Japanese sentence-mining workflow. It detects unique kanji in a note and automatically adds structured study data.

自分の日本語センテンスマイニングを効率化するために開発したAnkiアドオンです。ノート内の重複しない漢字を検出し、学習情報を自動入力します。

How it works仕組み

Hooks into note creation, parses CJK characters, then adds readings, meanings, stroke count, frequency, radicals and component data from a local dataset.

ノート追加時のフックでCJK文字を抽出し、ローカルデータから読み、意味、画数、頻度、部首、構成要素を取得して追加します。

Designed for use実用面

Supports bulk re-population, preserves existing fields by default, and packages both machine-readable JSON and a human-readable summary.

一括再生成に対応し、既存データは初期設定で保持。機械処理向けJSONと読みやすい要約を同時に保存します。
